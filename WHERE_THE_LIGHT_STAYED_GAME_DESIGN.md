# Where the Light Stayed

## Format
Browser-based interactive narrative OST experience.

## Runtime Goal
45–60 minutes.

## Core Experience
The player explores dreamlike memory spaces, interacts with symbolic objects, and unlocks music/text fragments that tell an emotional story about memory, growing up, and love.

## First Prototype
Scene 01: The Empty Room

## Prototype Requirements
- A 3D room or diorama
- Camera movement
- 3 interactable objects
- Text popup system
- Background music loop
- Smooth fade transitions
- Ending state after all objects are clicked

## Do Not Add Yet
- Save system
- Chapter select
- Multiple endings
- Complex puzzles
- Character models
- Voice acting
- Steam features
- Electron packaging
